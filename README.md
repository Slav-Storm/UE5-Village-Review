# UE5 Village Review

Visual design reviews for the UE5 village environment. **Start with [REVIEW.md](REVIEW.md)** for the latest images, changes, decisions and unfinished areas.

- [latest/](latest/): the current screenshots and a small provenance/camera manifest.
- [archive/](archive/): selected previous milestone reviews.
- [AGENTS.md](AGENTS.md): the update and publication workflow.

This independent repository contains only lightweight review material. The Unreal project, generated geometry, build output and production assets remain outside it.

For another ChatGPT conversation: open `REVIEW.md`, inspect its embedded images (or fetch the individual PNGs), and distinguish the current state from planned work. A GitHub connection must have access to this private repository; the ability to read repository text alone does not guarantee that a client renders images.

Updates happen when a visual review is requested, not on a background schedule.
